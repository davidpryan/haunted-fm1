Haunted FM-1

Five generative firmwares for the M-VAVE FM-1, each built around one idea: the shape of a song, a voice that almost says something, timing that is never on the grid, harmony as weather, a tape loop that wears out. Install one from this page with the FM-1 on USB (Chrome or Edge), or try it in the browser first. Version {{VERSION}}.

Install

Connect the FM-1 by USB, then press Install. The browser asks once to allow MIDI: allow it. Do not unplug while it writes. Connect the cable to the computer directly; no other MIDI software should have the FM-1 open.







  
Switching between them

  
Any of the five installs over any other, and over Felucca-family firmware, from this page. Going from
  M-VAVE's stock firmware works the same way. To go back to the stock firmware, use the section below or M-VAVE's own
  updater (M-UPGRADE). What a firmware saved on the FM-1 (its loop, its route, its settings) is kept by that firmware
  only while it is installed; save anything you care about before switching.
